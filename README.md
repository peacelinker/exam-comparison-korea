# 시험·구역예배 비교 분석

한 개의 `.xlsx` 파일을 브라우저 안에서 읽어 다음 두 가지 분석을 제공하는 정적 웹앱입니다.

- **시험 비교 분석**: A·D·G·I열을 이용해 이번 시험과 직전 시험의 지역별 현황을 비교합니다.
- **구역예배 비교 보고**: A·D·G·H열을 이용해 금번과 지난 구역예배의 참여 상태와 개인별 변화를 비교합니다.

## 개인정보 보호

> **개인정보가 담긴 엑셀 파일을 저장소에 절대 커밋하지 마세요.**

- 파일은 `File.arrayBuffer()`로 읽고 현재 브라우저 메모리에서만 처리합니다.
- `fetch`, 외부 API, 백엔드, 쿠키, 로컬 스토리지, 분석 추적 도구를 사용하지 않습니다.
- GitHub Pages에는 앱 코드만 공개하며, 사용자가 선택한 엑셀은 브라우저 메모리에서만 처리합니다.
- 새로고침하거나 `새 파일 분석`을 누르면 메모리의 분석 상태가 사라집니다.
- `.gitignore`는 `.xlsx`, `.xls`, `.xlsm`, `.xlsb`를 제외합니다.

## 실행

Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run dev
```

개발 서버가 안내하는 로컬 주소를 브라우저에서 엽니다.

## 테스트와 빌드

```bash
npm run test
npm run build
```

테스트는 시험 비교 회귀 동작과 구역예배 날짜 형식, 한국 날짜, 최근 7일 경계, H열 입력률, 자동 추천 3가지 경우, 상태 표준화, 중복·지역 이동 연결, 참여율, 단계하락·향상, 보고서 및 CSV 출력을 검증합니다.

샘플처럼 개인정보가 있는 파일은 저장소에 넣지 않고 로컬에서만 다음처럼 검산할 수 있습니다. 출력에는 이름 목록이 포함되지 않습니다.

```bash
npm run acceptance -- "C:\path\to\private-file.xlsx" 2026-07-23 0.5
```

구역예배 분석은 이름을 출력하지 않는 다음 인수 검산 명령으로 확인할 수 있습니다.

```bash
npm run acceptance:worship -- "C:\path\to\private-file.xlsx" 2026-07-23 0.5
```

## 판정 원칙

### 시험 비교

- 데이터 행은 D열에 이름이 있는 2행 이후 행입니다.
- 유효 입력률은 유효 시험 상태 수를 D열 이름 행 수로 나눈 값입니다.
- 빈값과 알 수 없는 값은 `미응시`로 바꾸지 않습니다.
- 유일한 이름은 지역이 바뀌어도 연결하고, 중복 이름은 `지역 + 이름`으로 한 번 더 확인합니다.
- 끝까지 중복이면 개인 전환 분석에서 제외하고 경고합니다.
- 수식은 재계산하지 않으며 파일에 저장된 현재 값만 사용합니다.

### 구역예배 비교

- 자동 탭 추천의 H열 입력률은 G열의 정식예배자 행을 기준으로 판정합니다.
- 실제 현황과 비교 보고서는 D열에 이름이 있는 고유 인원을 대상으로 H열 셀을 직접 집계하며, G열 값으로 인원을 제외하지 않습니다.
- H열은 `대면 모임`, `줌`, `통화`, `미참여`로 표준화합니다. 실제 사용 파일의 `대면모임`은 `대면 모임`, `X`는 `미참여`로 처리합니다.
- 자동 추천의 기준일은 파일을 선택한 시점의 `Asia/Seoul` 날짜를 내부에서 사용합니다.
- 최근 7일 이내 날짜 탭과 H열 유효 입력률을 이용해 금번·지난 탭을 추천하며, 사용자가 언제든 직접 변경할 수 있습니다.
- 분석 인원과 금번 현황은 금번 탭을, 지난 현황은 지난 탭을 각각 직접 집계합니다. 따라서 지난 탭에만 있는 인원과 지역 이동 인원도 지난 참여 합계에 포함됩니다.
- 개인별 단계 변화 명단만 두 탭의 `지역 + 이름`과 유일한 이름을 연결해 계산합니다.
- 구역예배 보고서의 지역 표시 순서는 `전체 → 서대문 → 마포 → 합정 → 신촌 → 새신 → 홍대 → 소성`이며, 그 밖의 지역은 뒤에 가나다순으로 표시합니다.
- 시험 보고서의 지역 표시 순서는 `전체 → 서대문 → 마포 → 합정 → 신촌 → 새신 → 홍대 → 소성`이며, 그 밖의 지역은 뒤에 가나다순으로 표시합니다.
- 시험 보고서의 지역 카드와 전체 현황에는 직전 시험 대비 `전체시험 증감`과 `정규시험 증감`을 함께 표시합니다.
- 시험·구역예배 상세 보고서의 인원 명단은 `A열 지역 B열 팀 C열 구역 이름` 형식으로 표시하며, 빈 소속 값은 `미입력`으로 표시합니다.
- 구역예배 상세 보고서의 명단은 시험 보고서와 동일하게 한 줄에 한 명씩 표시합니다.
- TXT 보고서와 CSV 집계 파일은 브라우저에서 즉시 생성하며 외부 서버로 전송하지 않습니다.
